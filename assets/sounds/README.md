# Chat and notification sounds

MP3 files for custom sounds (configured in `SoundService`):

- **send_message.mp3** – when sending a message (player choice)
- **received_message.mp3** – when receiving a message (NPC)
- **toast_sound.mp3** – notification/toast (system: toast, notify, new conversation)

If files don't exist, the app uses generated beeps as fallback.
